# Pemetaan Persebaran UMKM Sulawesi Utara (Web GIS)

Sistem Informasi Geografis (Web GIS) interaktif untuk memetakan dan memantau persebaran Usaha Mikro, Kecil, dan Menengah (UMKM) di wilayah Sulawesi Utara. Proyek ini dikembangkan melalui kolaborasi antara Program Studi D-IV Teknik Informatika, Jurusan Teknik Elektro, Politeknik Negeri Manado dan Yayasan Bina Lentera Insan (YBLI).

## Struktur Direktori

- `web-app/` : Aplikasi utama Web GIS berbasis React, Leaflet, dan Supabase.
- `scripts/` : Skrip Python untuk persiapan dan pengolahan data geospasial UMKM.
